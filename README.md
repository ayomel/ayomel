## Featured projects

### [LinguaPop](https://github.com/ayomel/LinguaPop)
A Chrome extension that helps you practice Spanish or French while browsing. It replaces selected words and phrases, offers translation tooltips, and saves vocabulary for flashcard review.

**Engineering focus:** reversible DOM changes, predictable word selection, dynamic page updates, and learning progress stored locally.

[Try the extension](https://github.com/ayomel/LinguaPop#try-it-without-building) · [Engineering case study](https://github.com/ayomel/LinguaPop/blob/main/docs/engineering-case-study.md)

### [FlickPick](https://github.com/ayomel/flickpicks)
Discover movies and TV shows, watch trailers, and keep a watchlist. A React and TypeScript frontend on Cloudflare connects to a Python FastAPI service.

**Engineering focus:** frontend/API integration, anonymous watchlist ownership, upstream caching, and CI checks for linting, types, tests, and builds.

[Live app](https://flickpick.mel-2cb.workers.dev/) · [API source](https://github.com/ayomel/flickpicks-api) · [Case study](https://melverton.com/projects/flickpick)

### [Shrinkcord](https://github.com/ayomel/shrinkcord)
Make oversized images and videos easier to share on Discord. Images compress in the browser; videos use an API for processing.

**Engineering focus:** browser workers, quality and size tradeoffs, asynchronous job status, and rate-limit retries.

[How it works and local setup](https://github.com/ayomel/shrinkcord#how-it-works)
